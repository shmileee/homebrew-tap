# Homebrew Tap

Install the tap:

```sh
brew tap shmileee/tap
```

Install Alacritty from its official, unsigned macOS release:

```sh
brew install --cask shmileee/tap/alacritty
```

The cask removes the quarantine attribute after installation. Renovate tracks
Alacritty releases and proposes version and SHA-256 updates together.
